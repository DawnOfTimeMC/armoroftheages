### Armor effects!
Each armor set now grant a dedicated armor bonus when the set is fully equiped. Each effect is very unique and linked to the armor theme. Some provides more mobility, other more projections, and even ones requiring sacrifices to bring you strenght!
**You can check the CF page if you are interested about all the effect details**

- Slightly improved the GUI config menu by merging the prefered skin type and armor skin menu
- Rebalanced all the armor stats to align them with vanilla MC : leather, iron, diamond, netherite

- Improved recipes to match the new armor tiers
- Improved the displayed armor names to match their new armor tiers
